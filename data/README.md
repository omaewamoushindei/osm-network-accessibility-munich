# Data

This project uses OpenStreetMap data accessed through OSMnx.

Raw OpenStreetMap data is not committed to this repository because it can be regenerated by running the notebook. This keeps the repository lightweight and avoids storing large derived geospatial files.

The notebook downloads:

- Munich walking-network data from OpenStreetMap
- public-transport-related features such as bus stops, tram stops, platforms, stop positions, and stations

Generated local data files, if any, are ignored by Git.
